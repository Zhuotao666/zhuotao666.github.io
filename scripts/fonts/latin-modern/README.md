# Latin Modern fonts

Original, unmodified Latin Modern 2.005 fonts from https://ctan.org/pkg/lm
(https://mirrors.ctan.org/fonts/lm.zip).

The CV embeds Roman 10 regular, bold, italic and bold italic, plus Roman 12
bold for the name, matching the original LaTeX CV's font family.
